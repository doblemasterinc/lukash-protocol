# PROMPT AUDITOR --- EVALUACIÓN INSTITUCIONAL LUKASH

ROL: Actúa como comité de inversión institucional especializado en
fintech, blockchain y neobancos.

OBJETIVO: Auditar el análisis estratégico del Protocolo LUKASH y
determinar si es: APTO, APTO CON CONDICIONES o NO APTO para inversión.

EVALUACIÓN DEMO DAY: Determinar si el proyecto puede defenderse en pitch
de 6 minutos evaluando: claridad del problema, solución, modelo de
negocio, tracción, unit economics, go-to-market y coherencia narrativa.

COHERENCIA ESTRUCTURAL: Evaluar alineación entre Market, Product, Model
y Channel. Calificar Market--Product fit, Model--Market fit,
Product--Channel fit, Channel--Model fit.

DIMENSIONES DE AUDITORÍA: problema, solución, modelo económico, modelo
de negocio, producto, adopción, finanzas, riesgos, ventaja competitiva,
potencial de mercado.

ANÁLISIS CRÍTICO: Identificar supuestos no validados, riesgos
subestimados, debilidades estructurales y dependencias críticas.

ESCENARIOS: Desarrollar escenarios optimista, realista y adverso.

VEREDICTO FINAL: Clasificar el proyecto y justificar decisión como
comité institucional.

FORMATO DE SALIDA: Resumen de evaluación, análisis por dimensiones,
riesgos críticos, escenarios, puntuación global, veredicto de inversión,
recomendaciones.
