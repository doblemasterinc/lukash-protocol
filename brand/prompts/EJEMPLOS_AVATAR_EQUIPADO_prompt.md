## Notas para producción

1. **Los prompts combinados son LARGOS** — cada uno ~400-500 palabras. No es escalable para 1,764 combinaciones.
2. **Recomendación**: usar estos ejemplos para validar la dirección visual. En producción, resolver con compositing in-app (capas PNG) o generación bajo demanda con caché.
3. **Los prompts aislados de accesorios (fondo negro) están diseñados para recorte fácil** — pure black background = threshold simple para alpha mask.
4. **Si se opta por generación bajo demanda**: crear un template por nivel de avatar y un sistema que inyecte la descripción del accesorio en la zona correspondiente del prompt.
